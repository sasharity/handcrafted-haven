Handcrafted Haven

- Handcrafted Haven is a web application that provides a platform for artisans and crafters to showcase and sell their unique handcrafted items. It serves as a virtual marketplace, connecting talented creators with potential customers.

### Technologies:
1. Front-End: HTML, CSS, JavaScript, TypeScript, Next.js
2. Back-End: Node.js
3. Deployment/ Cloud Platform: Vercel
